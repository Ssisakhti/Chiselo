## About Text

```text
Chiselo is a macOS visual HTML editor for existing webpages. It supports direct rendered-page editing, source preservation, protected saving, responsive preview, change review, and HTML/PDF/PPTX delivery.
```

## Website Copy

```text
Chiselo edits existing HTML. It does not create HTML projects. Select rendered page objects directly and edit text, images, tables, and styles. Other objects remain stable while you edit one element. Selection geometry and the canvas remain stable during text entry. Image replacement, rollback, and signed incremental updates are included.
```
